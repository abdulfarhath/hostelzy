# F12 · Room layout editor and room layers

**Stage:** Idea

## Problem
Tenants want to know where fans, AC, windows and the washroom are relative to their bed.

## What it does
- Owner: edit each room's layout: move beds, windows, door, washroom, fans, AC.
- Tenant: room plan with toggles (fans, AC, windows, washroom) to see what's near each bed.
