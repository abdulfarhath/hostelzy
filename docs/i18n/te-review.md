# Telugu: strings to translate (owner and resident first)

For the founder or a native Telugu speaker. **No machine translation**: write each line the way a PG owner or resident in Hyderabad would say it.

How it works:
- Put each translation into `hostelzy/assets/l10n/app_te.arb` as `"English text": "తెలుగు"`. Lines left out show in English.
- When a native speaker has checked the file, set `"@@reviewed": true`. Until then the picker shows "తెలుగు (beta)".
- Text with a name or number inside (₹, bed numbers, counts) shows in English for now; fixed text comes first.
