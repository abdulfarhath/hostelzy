## Rules for every reel

| Rule | Why |
|---|---|
| Film a real PG only with the owner's OK, and only one that joined | DECISIONS / README ground rules |
| App screens showing sample hostels get a label: **"Sample hostel"** | No fake listings |
| Never film residents' faces, names, gates, CCTV or exits | Safety rule (F12) |
| No "verified", no "guaranteed", no made-up numbers | Honesty |
| Real numbers only: ₹3,000 advance, 30 days notice, ₹1,000–1,500 maintenance are Hyderabad norms (DECISIONS); a PG's own rent only from that PG | Honest examples |
| Captions in simple English; add Telugu/Hindi text on screen where it helps | Our audience |
| 15–30 seconds, vertical, text on screen (most watch muted) | Reels format |
